# Getting Help

There are a few ways to connect with the FIDOpower project:

* Send an email to fidopower+help@lists.lfenergy.org
* Submit an issue on the [repository](https://github.com/orgs/fidopower/repositories) for the FIDOpower module you need help with.

## How to Ask for Help

If you have trouble installing, building, or using FIDOpower, but there's not yet reason to suspect you've encountered a genuine bug,
start by posting a question to the [mailing list](fidopower+help@lists.lfenergy.org). This is the place for question such has "How do I...".

## How to report a bug or request an enhancement

FIDOpower manages bug and enhancement using it's [issue tracker](https://github.com/fidopower/.github/issues). The issue template will guide you on making an effective report.

## How to report a security vulnerability

If you think you've found a potential vulnerability in FIDOpower, please
email security@lfenergy.org to responsibly disclose it.

## Contributing a fix

Please refer to [CONTRIBUTING.md](CONTRIBUTING.md) to make a project contribution.
