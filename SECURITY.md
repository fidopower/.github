# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.0   | :white_check_mark: |
| 0.0.1   | :x:                |

## Reporting a Vulnerability

Please file an issue for any vulnerability you discover on the corresponding repository. For a list of FIDOpower repositories, see https://github.com/orgs/fidopower/repositories.
